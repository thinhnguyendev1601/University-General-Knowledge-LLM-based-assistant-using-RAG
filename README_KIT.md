# Week-1 kit: corpus, schema, annotation guide, eval skeleton

Unzip into the repository root (folders merge with yours). Then:

```bash
pip install -r requirements.txt
pytest                                   # 7 tests should pass
```

Read in this order: `docs/00_week1_checklist.md` → `01_corpus_v0_guide.md` → `03_annotation_guide.md` → `02_chunk_schema.md` → `04_eval_skeleton.md`.

Append `.gitignore.snippet` to your `.gitignore`. `core/` is a proposal for your shared contracts — merge it with the contracts you write today rather than keeping two copies.
